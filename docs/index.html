Open source portfolio project

Bargain

A full-stack online auction platform for auctioneers, bidders, and administrators — built with Yii2, PHP, and PostgreSQL.

PHP Yii2 PostgreSQL Bootstrap 5 RBAC
View source on GitHub Run locally

What it does

  • Auctioneers — create auctions, manage listings, subscription plans, and sales stats
  • Bidders — browse, search, bid, track activity, and view transaction history
  • Admins — moderate users and auctions, handle complaints & support, audit log, payments
